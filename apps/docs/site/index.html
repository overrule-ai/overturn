From a human correction
to a replayable test.

  1. Record

    Wrap the model client you already have. Every prompt, tool call and answer is recorded with a fingerprint.

  2. Correct

    A human approves, edits, rejects or escalates — in the app, in Slack, or inside your own product. The case freezes with the fix.

  3. Replay

    One command runs the suite against any model or prompt. Side-effect tools are refused, never executed.

  4. Report

    Regressions first, then still wrong, then fixed — baseline, target and the human's correction side by side.

Regressions first.
Everything else after.

Replayed, not re-executed. Side-effect tools are refused, every tool answer comes from the recording, and the receipt at the bottom of each report says exactly what was and wasn't tested.

Cases come from real corrections

Not hand-written datasets. Every approve, edit, reject or escalate becomes a case with the human's answer attached, scored on the decision fields — not the prose — so a different phrasing is never a regression.

Safe replay

Tool calls are matched to recordings by fingerprint, not by position, so a model that takes a different path still gets the right answers where they exist. Nothing is emailed, refunded or written twice.

Model-agnostic

OpenAI, Anthropic, Vercel AI SDK and OpenTelemetry in. Compare models and prompt versions in one case × model matrix. Gate pull requests with the GitHub Action.

Three lines to
your first replay.

Install the SDK, wrap the client you already have, replay. Self-host on one Postgres or sign in at app.overturn.run — the CLI is the same either way.

# install
$ npm i @overturn-ai/sdk

# replay every correction against a new model
$ overturn replay --model anthropic/claude-sonnet-4-5
25 cases · 2 regressed · 7 fixed · 8 still wrong · 8 passed
regression  approve  ticket-triage T-1020   1/2 fields match
fixed       edit     ticket-triage T-1004   expected fields match
import { Overturn } from "@overturn-ai/sdk";
import OpenAI from "openai";

const ov = new Overturn();                 // OVERTURN_API_KEY
const openai = ov.wrapOpenAI(new OpenAI()); // every call recorded

const run = ov.startRun({ agent: "triage", input: ticket });
await run.context(async () => {
  const res = await openai.chat.completions.create({ model, messages });
  run.end({ output: res.choices[0].message.content });
});
